# 界面示意素材

这三张图由历史 RGB 照片与对应人工标注生成，用于说明界面布局、类别和数量的呈现方式。物品框、类别与数量来自标注；圆桌轮廓由可见桌沿手动取点后进行二维椭圆拟合。

它们不是模型预测截图，也没有运行深度过滤或跨帧计数。未显示模拟置信度或耗时。

- `1978_annotation_ui.jpg`：方桌整体界面。
- `2295_annotation_ui.jpg`：圆桌界面与桌沿拟合示意。
- `A54_annotation_ui.jpg`：包含桌外干扰的方桌场景。

图中保留原标注，不对标注正确性作额外保证。标注来源、哈希与数量见 [manifest.json](manifest.json)。
