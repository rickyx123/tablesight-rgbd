# 工具演示数据

本目录全部为人工构造数据，不是竞赛预测或真实实验结果。CSV 的图片路径与 SHA 是示意值；不附对应图片。

计数 JSONL 每行是一组场景/试次；真实真值与预测分别放 ground_truth、prediction，元素为 table、goal_id、count。空桌在 tables 中声明。失败预测应保留为空预测，不从统计里删除。

重复一致性按同一 scene_id 与 pipeline 的试次两两比较。背景指标需另行人工标注独立桌外物品数和其中被误计的数量，不能从最终类别清单反推背景归属。

采样工具默认只处理清单结构；真实数据可加 --check-files 核对路径存在。它不自动检查图片是否可读，也不取代原项目的 LabelMe/类别/框坐标与近重复审计。
