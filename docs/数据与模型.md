# 围绕现场失败，建立数据与模型迭代闭环

[返回项目首页](../README.md) · [技术复盘](技术复盘.md) · [代码与运行](运行说明.md)

项目中最明显的模型提升，发生在把现场失败转化为具体补拍任务之后。我们没有把所有问题都交给置信度阈值：先区分外观漏检、容量错分、桌面误归属和后处理过滤，再决定是否需要新数据。

## 怎么设计补拍

我负责数据集拍摄建议与图像标注。补拍围绕实际失败因素展开，避免只增加同一布置的连拍数量。

| 失败现象 | 补拍重点 |
|---|---|
| 桌子较远，TABLE 容易漏检 | 距离、俯角和桌面在画面中的位置 |
| 350ml 与 550ml 容易混淆 | 同品牌双规格对照、姿态变化与遮挡 |
| 眼镜、胶带、卷尺、遥控器漏检 | 小目标尺度、正反面、旋转角度与背景对比 |
| 换到现场后表现下降 | 真实地板、反光、阴影、包装与现场摆放 |
| 地上物品被误算到桌上 | 桌外同类、桌后垫高、桌边真物的对照场景 |

从单物品对照开始，再补少量物品组合，最后覆盖真实现场的复合干扰。这样更容易判断模型究竟缺哪一种信息。

## 标注和验证如何保持一致

类别契约统一为 16 类常见物品与 TABLE。容量以实物记录核对，不用瓶盖颜色或模型预测反向决定标签。未标注照片也不能直接当作没有物品的负样本。

同一原图的 JPG、遮罩图和裁剪图需要关联物理来源；连续拍摄的相近画面按场景分组，避免近重复图跨训练与验证。另保留 602 张核心验证图，观察新数据加入后旧场景能力是否回退。

## 模型怎样迭代

这些阶段的基础架构都是 **YOLOv8m**；V6–V9 是项目内部权重版本编号。

| 版本 | 唯一训练图 | 验证图 | 主要变化 |
|---|---:|---:|---|
| V6 | 2406 | 602 | 困难样本增加采样频率 |
| V7 | 2871 | 718 | 修订标签、增加专项数据并调整采样 |
| V8 | 3465 | 867 | 加入现场照片，从 V7 微调 |
| V9 | 3691 | 924 | 加入新现场批次，从 V8 微调 |

V9 将新现场、上一批现场、旧专项和普通图像按 **7 / 5 / 3 / 1** 的重复频率写入训练清单，共形成 8219 个加权条目。它改变的是图像被采到的频率，不是直接修改分类损失的权重；唯一图片数仍是 3691。

## 改进是否有效

下表每一行都在相同图像与标签上比较两个模型；各行之间的验证集不同。

| 对比 | 验证范围 / 输入 | mAP50–95 变化 |
|---|---|---:|
| V6 → V7 | 718 张 / 832 | 64.58% → 68.92% |
| V6 → V7 | 718 张 / 640 | 60.83% → 65.73% |
| V7 → V8 | 现场 149 张 / 832 | 51.80% → 71.73% |
| V8 → V9 | 新现场 57 张 / 832 | 56.64% → 68.62% |
| V8 → V9 | 旧困难 100 张 / 832 | 65.58% → 64.66% |

现场能力得到明显改善，旧专项也确实存在回退。因此接受新模型需要同时查看新现场、旧专项与固定核心集，不能只挑一组上涨的数据。

这些迭代同时改变了数据、标签、采样和微调策略，尚不能把提升单独归因于“加权”。验证集也参与过模型选择，需要额外封存的新场景测试来评估泛化；模型 mAP 不代表最终逐桌计数准确率。

## 可以继续做的实验

在相同数据和训练预算下，对比均匀采样与困难样本重采样；分别观察新现场提升、旧能力回退与训练成本。再把检测指标与系统指标结合起来，统计逐桌完全正确率、数量误差和桌外误计，而不是只看单帧检测框。
