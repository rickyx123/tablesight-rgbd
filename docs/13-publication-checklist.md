# 从私有整理稿到公开仓库

- [ ] 核对官方赛事名称、赛项、年份、奖项及证书材料。
- [ ] 确认团队署名与个人分工，取得需要的代码/图像公开许可。
- [ ] 选定 README 的核心案例，移除不准备公开的素材。
- [ ] 确认比赛稳定版、历史版本和取消实验的状态。
- [ ] 给模型和数据分别说明来源、下载条件与使用范围。
- [ ] 按 Ultralytics、OCR、OpenNI、Ascend 及其他实际依赖核对许可证；本稿暂不擅自指定整个项目为 MIT。
- [ ] 原始图片、模型权重、私钥、口令、机器标识与个人路径不直接提交。
- [ ] 核验公开的数字都能指向同一集合、同一设置或明确的历史报告。
- [ ] 视频、截图和实际结果对应同一输入；实验与回放注明。
- [ ] 在干净环境运行仓库的评估工具和采样工具。
- [ ] 如需学术引用，再补齐作者信息和 CITATION.cff；本稿不制造 DOI 或论文信息。
