# 项目定位与技术贡献

## 问题定义

输入同一相机采集的 RGB 图像和深度，以及有限时长的图像序列；输出每张目标桌面上物品的类别和数量。约束包括边缘算力、相机启动时间、遮挡、旋转、透明材质、二维贴图和桌外同类物品。

任务可以拆成三个问题：外观属于哪一类；物品是否属于目标桌面；跨帧对应几个真实实例。检测框本身不能回答全部问题。

## 可采用的贡献表述

1. **场景驱动的数据与模型迭代**：从现场失败样本出发补拍，按物理原图和场景组隔离数据，按优先级重采样，并用固定核心集检查旧能力。
2. **支撑区域感知的桌面筛选**：方桌保留透视四边形，圆桌利用深度与图像边界；针对桌后垫高物避免仅按视觉高度决定归属。
3. **显式保留深度不确定性**：把可靠立体、可靠平面和未知分开，透明、反光和遮挡造成的缺失不直接等同贴纸。
4. **面向数量的时序聚合**：区分单帧检测、轨迹支持和最终实例数量，对有效桌面帧进行归一化。
5. **可追溯的异构部署**：导出、类别顺序、预处理与后处理一致性检查，配合版本哈希、单独回放和回退机制。

这些是工程与研究表达的候选主线。现阶段没有证据支持“提出全新检测网络”“完成开放世界识别”或“所有场景零误检”等更强结论。

## 适合延伸的方向

- 机器人场景中的 RGB-D 几何感知与物体支撑关系。
- 遮挡与缺失深度下的多证据决策。
- 旋转场景中的时序实例计数与不确定性传播。
- 边缘视觉系统的精度、时延与可靠性联合评估。

OCR 四类是预先约定的文本定义类别；这项能力与任意新类别识别、视觉语言大模型推理的范围不同。
