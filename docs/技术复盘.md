# 8 个视觉与检测实践案例

[返回项目首页](../README.md) · [数据与模型](数据与模型.md) · [代码与运行](运行说明.md)

这篇分享围绕一个问题展开：从识别画面中的物品，到统计目标桌面上的实物，还需要哪些证据？前半部分关注数据和检测模型，后半部分关注几何、深度与连续帧融合。

## 1. 到现场后，为什么模型突然漏检？

训练环境中能识别的物品，换了距离、地板、光照和摆放后更容易漏检。

**原因分析。**模型可能依赖熟悉的背景、尺度或包装正面；反复调低阈值只能增加候选，也可能带来更多误检。

**处理思路。**先按失败因素设计补拍：单物品角度与尺度对照、少物品遮挡组合、真实现场复合场景；标注后微调，用同集比较验证变化。

**结果与局限。**V7→V8 在同一现场 149 张、832 输入上，mAP50–95 从 51.80% 升至 71.73%。数据、标注、采样和微调同时变化，不能分离单项贡献。

**值得分享的经验。**如何把失败样本转化成采集方案，而不是只增加相似连拍。

## 2. 困难样本加权有效，为什么旧场景反而下降？

新增现场样本带来提升，但部分旧困难类别出现回退。

**原因分析。**数据数量、采样频率和微调共同改变训练分布；单看新现场无法判断模型整体是否更好。

**处理思路。**用图像级重采样提高困难场景频率，保留固定核心集和旧专项集。V9 按新现场、上一批现场、旧专项、普通图像采用 7/5/3/1 频率；同一原图的派生版本不跨训练与验证。

**结果与局限。**V8→V9 新现场 57 张 mAP50–95 为 56.64%→68.62%，旧困难 100 张为 65.58%→64.66%（均为832输入、各组内部同集）。当前没有均匀采样对照实验来单独量化加权收益。

**值得分享的经验。**采样权重、网络参数和置信度阈值的区别，以及如何监控遗忘。

## 3. 同品牌不同容量的水，为什么容易识别错？

350ml 与 550ml 包装相似，旋转和透视下容易互相混淆。

**原因分析。**包装、瓶盖颜色和画面高度不是可靠容量真值；模型可能学到捷径，同一实例跨帧也可能出现竞争类别。

**处理思路。**按实物记录核对标签，补同品牌双规格及不同姿态对照；汇总时把同一实例的类别竞争与真实数量分开处理。

**结果与局限。**历史模型评估仍将容量错分列为弱项，没有证据支持容量问题已经全部解决。后续适合按品牌、距离和遮挡分别统计混淆。

**值得分享的经验。**相似类别的标签语义、对照采集与实例级类别冲突。

## 4. 识别出了物品，怎样判断它真的在桌上？

桌后垫高的薯片、方便面看起来与桌面齐平，容易被矩形区域收入。

**原因分析。**检测框只描述外观位置；高度接近也不能证明物体由真实桌面支撑。斜视方桌实际是透视梯形。

**处理思路。**用 TABLE 候选、深度支撑和图像桌沿形成四边形，约束后沿扩张；同时检查桌边真物，避免一味缩框。

**结果与局限。**后沿修复有七帧专项回放记录，尚不是跨所有视角的可靠性结论。适合继续测试桌沿遮挡、远距离与垫高背景物。

**值得分享的经验。**从检测框走向支撑区域与物体归属判断。

## 5. 贴纸有外观，透明瓶缺深度，怎样避免两边误删？

贴纸可能因局部噪声或邻物高点被保留，真实透明瓶又可能缺少有效深度。

**原因分析。**框内有高点不表示高点属于该物体；缺失深度不等于平面，单个毫米阈值也不适合所有物品尺度。

**处理思路。**区分立体证据、可靠平面和未知三种状态；结合有效区域、空间归属与物品尺度判断，不让邻物凸起替贴纸背书。

**结果与局限。**保留 UNKNOWN 是减少误删的设计取舍，不代表贴纸全部过滤成功。下一步应同时评估贴纸漏过滤率与实物误删率。

**值得分享的经验。**缺失信息如何进入决策，以及几何残差为何不一定是真实竖直高度。

## 6. 旋转时桌面框突然扩大，为什么不能锁死首帧？

圆桌框有时向右膨胀，把地面同类物品纳入；固定首帧又跟不上实际移动。

**原因分析。**偏心转动、遮挡和透视会改变视觉边界，桌面也不一定围绕理想圆心旋转。

**处理思路。**从当前检测出发，用深度、图像边界与短时一致性约束异常膨胀；证据充分时更新几何，避免永久固定中心和半径。

**结果与局限。**开发记录支持该定位思路；仍需用固定序列量化边界偏差和桌外误计，不能宣称任意场景完全不漂移。

**值得分享的经验。**动态区域定位中，当前观测与短时历史如何平衡。

## 7. 视频里经常出现眼镜，为什么最后少算？

眼镜等小物品随角度间歇漏检；桌面漏检也减少了物品的有效计票机会。

**原因分析。**统一的绝对帧数和双帧要求可能对视角敏感类别过严；直接累加检测框又会把同一物体算多次。

**处理思路。**结合有效桌面观测和跨帧实例支持进行聚合；后期针对眼镜放宽双帧确认。通过逐帧记录区分检测漏检、桌面筛选与最终计票不足。

**结果与局限。**这些是历史调试与规则迭代，尚缺统一的独立序列消融。应同时报告召回、重复计数、数量误差与重复测试一致性。

**值得分享的经验。**检测置信度、出现帧数与最终实例数量不是同一个指标。

## 8. 文字明明清楚，为什么识别没进入最终结果？

文字标签贴在真实书本或瓶身上；裁剪区域、竖排文字和空间筛选都可能让最终文字类别缺失。

**原因分析。**文字检测、裁剪、缩放、识别和桌面归属是不同环节；圆桌不同帧的位置也不能直接混用。

**处理思路。**分别检查原图、裁剪和识别输出；对约定词汇使用可归类的部分字符，结合来源与位置处理，防止跨帧 OCR 错删物品。

**结果与局限。**全图兜底曾尝试后取消，不作为正式能力。部分字符匹配也有误触发风险，需在独立文本样本上评估。

**值得分享的经验。**OCR 的识别能力与区域选择、几何归属之间的关系。
