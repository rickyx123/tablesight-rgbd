## 可挑选的表达方向

- **数据闭环方向**：围绕现场错误设计补拍、维护场景分组和核心验证集，实施困难样本重采样并对模型做同集对比。
- **算法方向**：参与 RGB-D 支撑区域、深度不确定性和旋转场景的时序计数，利用失败归档定位错误来源。
- **部署方向**：参与 PT/ONNX/OM 一致性核对、算力分工、有限降级、版本回退和实机验证。

将本人确实承担的内容转换成第一人称；用一到两个有来源的指标支撑，不把系统所有功能都写成个人原创算法。

## 面试讲述顺序

问题与限制 → 初始方案 → 一个具体失败 → 用什么证据排查 → 修改哪一层 → 同条件结果 → 还没解决什么。可以优先选择“垫高物不属于桌面”“有效帧比例”和“采样权重不是 loss 权重”三个故事。
