# 离线工具的定义与边界

Windows 中文目录在部分 Python 版本中需要显式开启 UTF-8，示例命令统一使用 `python -X utf8`；无需改动系统区域或全局编码配置。

## 计数指标

- 逐桌完全正确率：同一桌上所有类别数量向量与真值一致的桌数 / 总桌数。
- 场景完全正确率：该行所有桌都正确的场景记录数 / 总记录数。
- 逐桌数量 MAE：每桌各类别数量绝对误差之和，再对桌平均。
- 相对数量绝对误差：全部绝对误差 / 真值物品总数；真值总数为零时返回 null。
- 重复一致性：同场景、同 pipeline 的预测向量在全部试次对中的相同比例；少于两次不计算。
- 背景误计率：人工标注的独立背景实物中被误计的比例。不能把重复预测事件数当独立实物数。

数量一致性不等于正确率：每次都输出同一个错误数量，也可以有很高的一致性。

## 采样工具

输入包含场景组、物理原图 SHA、集合、路径和整数权重。拒绝场景组跨集合、物理原图跨集合、重复输入路径及验证/测试权重不为一。

训练中重复的是清单条目；图片文件不复制多份。同图所有类别都受到影响。工具不改变 loss、优化器或框标签，也不验证底层训练库是否去重；真实训练仍须核对 loader。

这两个工具是本次整理新加入的辅助代码，不声称它们已用于赛事。
