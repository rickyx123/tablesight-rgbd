## 不接设备也能运行

需要 Python 3.10 或更新版本。以下工具只使用标准库：

```bash
python -X utf8 -m pip install -e .
python -X utf8 -m tablesight.evaluate examples/counting_demo.jsonl
python -X utf8 -m tablesight.sampling examples/sampling_demo.csv --output weighted_train.txt
```

评估工具读取每次逐桌预测与真值，计算完全正确率、数量 MAE、重复测试一致性及背景误计。采样工具生成加权图像清单，并检查场景与物理来源是否跨训练和验证集合。

示例是人工构造的输入，用来演示工具，不是比赛实测数据。

## 验证工具与仓库

```bash
python -X utf8 -m unittest discover -s tests -v
python -X utf8 scripts/check_repository.py
```

检查覆盖工具行为、文档相对链接、原始指标文件与参考源码的哈希。硬件参考代码还依赖 OpenNI、Ascend ACL 及图像处理环境，安装约束见[参考源码说明](../reference/README.md)。
